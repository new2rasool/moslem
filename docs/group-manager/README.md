# 📚 کتابخانهٔ سند تفصیلی — ربات مدیریت گروه حرفهای تلگرام

این پوشه، نسخهٔ **تفصیلی** سند `docs/group-manager-features-fa.md` است. هر فایل یک ماژول کامل را با
جزئیات سطح پیادهسازی شرح میدهد: دستورها، نامهای فارسی/انگلیسی، سطح دسترسی، پارامترها، پیشفرضها،
جریان رفتاری (Flow)، حالتهای لبه (Edge Cases)، قالب پیامها و نکتههای فنی.

---

## راهنمای مطالعه (Legenda)

| نماد | معنی |
|---|---|
| `cmd` | دستور انگلیسی |
| «فرمان» | دستور فارسی معادل |
| 🟢 کاربر عادی | هر عضو گروه |
| 🟡 مدیر میانی (Mod) | ارتقایافته با `promote` |
| 🔵 ادمین ربات (Admin) | کنترل کامل ماژولها |
| 🔴 مالک گروه/ربات | خالق گروه یا مالک ربات |
| ⚫ سودو | Owner/Sudo سراسری |
| `[اختیاری]` | پارامتر اختیاری با پیشفرض مشخصشده |
| زمان | پیشفرضها: `30s` = ثانیه، `10m` = دقیقه، `2h` = ساعت، `3d` = روز، `1w` = هفته؛ ترکیب مجاز: `1d6h30m` |

> **قاعدهٔ عمومی:** هر دستور با ریپلای (`reply`) یا ذکر هدف (`@user` / `123456789` / `@channel`) کار میکند.
> همهٔ دستورها با پیشوند `/` یا `!` یا `.` یا معادل فارسی («بن»، «بن ۲ ساعت») پذیرفته میشوند.
