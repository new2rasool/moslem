# ماژول ۹ — پنل مالک/سودو و فدراسیون (Owner, Sudo & Federation)

این ماژول فقط در **پیوی ربات با مالک** (و سودوهای تعیینشده) در دسترس است. همهٔ دستورها ⚫ هستند.

---

## ۹.۱. پنل اصلی مالک (دکمهای در پیوی)

```
👑 پنل مالک — وضعیت: ۴۲ گروه فعال
├─ 📣 پیام همگانی (Broadcast)
├─ 👥 گروهها (لیست/جستجو/مدیریت)
├─ 🚫 لیست سیاه سراسری (GBan)
├─ 🏢 فدراسیونها
├─ 👤 سودو و ادمینهای ربات
├─ 📊 آمار سراسری
├─ ⚙️ تنظیمات پیشفرض و Preset ها
├─ 🔁 بکاپ و انتقال
└─ 🛠 حالت نگهداری
```

---

## ۹.۲. پیام همگانی (Broadcast)

| دستور/دکمه | رفتار |
|---|---|
| `/broadcast` | دریافت متن/مدیا (فوروارد یا ریپلای به پیام مالک) |
| `broadcast <text>` | ارسال مستقیم |
| گزینهها (دکمه پس از دریافت پیام) | `همهٔ گروهها` · `فقط گروههای فعال (۷ روز) ` · `گزینهای (انتخاب دستی از لیست)` · `بر اساس تگ (مثل #music یا #news)` |
| دکمهٔ `🚀 شروع` | اجرا با صف |

**رفتار مهندسیشده:**
- ارسال با **صف ۳۰ پیام/ثانیه** (تلگرام: ۳۰ msg/s برای رباتهای عادی)؛ بین هر پیام `sleep` تطبیقی با ردگیری 429 و `retry_after`.
- شمارندهٔ زنده: «ارسال شد: ۲۳/۴۲ — موفق ۲۲، ناموفق ۱» + دکمهٔ `⏸ توقف` (متوقفکردن امن بین دو ارسال).
- گزارش نهایی به مالک: فهرست گروههای ناموفق + دلیل (ربات اخراج شده؟ گروه بسته؟).
- **درج نام گروه** با `{chat}` در متن پیام؛ `+mention` برای منشن همه (فقط با تأیید دومرحلهای).
- زمانبندی: `broadcast schedule <timer-style>` (ماژول ۷.۱).

---

## ۹.۳. مدیریت گروهها

| دستور | رفتار |
|---|---|
| `groups [page]` | فهرست: نام، آیدی، اعضا، وضعیت (فعال/آخرین پیام)، تگها |
| `group <id|@>` | جزئیات: تنظیمات خلاصه، آمار امروز، تعداد ادمینها |
| دکمهها | `خروج ربات` · `🔇 خاموشکردن ربات در این گروه` (فقط پاسخ «ربات در نگهداری است») · `📋 لاگ گروه` · `حذف دادهٔ گروه` (GDPR) |
| `settag <گروه> <tag>` | برچسبگذاری برای Broadcast هدفمند |
| `searchgroup <text>` | جستجو بر اساس نام |

## ۹.۴. لیست سیاه سراسری و فدراسیون

### GBan (مدیریت)
فهرست کامل با علت/تاریخ/عامل (`gbanlist`)، جستجو (`gbansearch <id>`)، حذف (`ungban`)، و **اکسپورت** لیست به JSON برای اشتراک با ادمینهای دیگر رباتها.

### فدراسیون (Federation) — برای شبکههای چندگروهی
| دستور | رفتار |
|---|---|
| `fed create <name>` | ساخت فدراسیون (مالک) و دریافت `fed_id` |
| `fed join <fed_id>` | اتصال این ربات به فدراسیون (تأیید توسط سازندهٔ فدراسیون) |
| `fed leave <fed_id>` | قطع اتصال |
| `fed gban <id> [reason]` | بن در همهٔ گروههای عضو فدراسیون (با تکرار پیام علت) |
| `fed list` / `fed groups <fed_id>` | اعضا/گروهها |
| `fed sync` | همگامسازی لیست سیاه با فدراسیون (دستی؛ خودکار هر ۶ ساعت) |

- **پیادهسازی:** هر ربات، فدراسیونها را با «توکن عمومی فقط-افزودن» میشناسد؛ لیست سیاه بهصورت «دلتا + نسخه» (versioned) همگام میشود تا از ترافیک اضافه جلوگیری شود. نمونهٔ متنباز مرجع: Rose / MBT Federation.

## ۹.۵. سودوها و ادمینهای ربات
| دستور | رفتار |
|---|---|
| `addsudo <id>` / `delsudo <id>` / `sudolist` | مدیریت سودوها |
| `setglobaladmin <id>` | ادمین سراسری: میتواند در همهٔ گروهها تنظیمات بدهد ولی به پنل مالک دسترسی ندارد |
| `ownerlog on/off` | کانال لاگ سراسری |

---

## ۹.۶. تنظیمات پیشفرض و قالبها
- `setdefaultpreset <easy/standard/strict>` — پروفایل گروههای تازهنصب.
- `setglobalwelcome <text>` / `setglobalrules <text>` — قالب اولیهٔ همهٔ گروهها (گروهها میتوانند بازنویسی کنند).
- `setforcemenu` — فعالکردن دکمهٔ «نصب» در همهٔ گروهها؟

## ۹.۸. بکاپ، انتقال و نگهداری
| مورد | توضیح |
|---|---|
| `/backup` | خروجی کامل JSON (تنظیمات گروهها + GBan + فدراسیونها) به پیوی مالک؛ حداکثر ۱ بار/روز |
| `/export <chat_id>` | تنظیمات یک گروه (برای انتقال به گروه جدید) |
| `/import <chat_id>` (ریپلای به فایل) | بازیابی |
| `/maintenance on/off` | حالت نگهداری: همهٔ گروهها «🛠 ربات در حال بهروزرسانی است — بهزودی» |
| `/restart` | ریاستارت امن (با ذخیرهٔ صفها) |

---

## ۹.۹. احراز هویت دستورهای مالک
- دستورهای حساس (broadcast، gban، maintenance، backup) با **کد تأیید ۴رقمی یکبارمصرف** (`/confirm <code>` ارسالشده به مالک) محافظت میشوند — جلوگیری از اجرای فرمان توسط پیامِ فورواردی/جعلی.
- همهٔ اکشنهای مالک در کانال `ownerlog` ثبت میشود (حسابرسی سطح مالک).
- اگر ربات چند نمونه (Shard) دارد، پنل مالک فقط به نمونهٔ اصلی (`primary`) وصل است؛ سایر نمونهها وضعیتشان را push میکنند.
