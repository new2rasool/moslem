# ماژول ۶ — فیلترهای سفارشی، نوتها و پاسخ خودکار (Filters, Notes & Auto-Reply)

هدف: **بانک دانش گروه** — پاسخ خودکار به پرسشهای پرتکرار، حذف کلیدواژههای ناخواسته، و نوتهای
اداری برای پاسخهای سریع تیم مدیریت.

---

## ۶.۱. فیلتر کلیدواژهای (Custom Filters)

### دستورها
| دستور | سطح | رفتار |
|---|---|---|
| `filter <keyword>` (ریپلای) | 🔵 | ذخیرهٔ پیامِ ریپلایشده بهعنوان پاسخ برای آن کلیدواژه |
| «فیلتر» | 🔵 | معادل فارسی |
| `filter <keyword> <text>` | 🔵 | ساخت فیلتر متنی بدون ریپلای |
| `stop <keyword>` | 🔵 | حذف فیلتر |
| `filters [page]` | 🟢 | فهرست فیلترها (۲۰تایی + دکمهٔ صفحه) |
| `rmfilters` | 🔴 | حذف همهٔ فیلترهای گروه |
| `setfilter action <reply/delete_reply>` | 🔵 | فقط پاسخ / حذف پیام + پاسخ (پیشفرض: فقط پاسخ) |
| `setfiltermode <word/glob/regex>` | 🔵 | حالت تطبیق |

- محدودیت: ۵۰ فیلتر در هر گروه (پیشفرض؛ `setfiltermax <n>`).
- پاسخ میتواند: متن، عکس، ویدیو، گیف، استیکر، فایل، **آلبوم** یا ترکیب متن+دکمه باشد.

### الگوریتم تطبیق (Match Engine)
1. نرمالسازی متن (همان ۶ مرحلهٔ ماژول ۲.۳: حذف فاصلهٔ کاذب، تکرار، یکسانسازی عربی، ZWJ، leet).
2. تطبیق بر اساس حالت:
   - `word`: کلمهٔ کامل مرزی (با `\b` برای لاتین و «حد کلمهٔ سفارشی» برای فارسی: جداشکن = فاصله، نیمفاصله، علائم).
   - `glob`: `*` شروع/پایان («*سوال*») یا Wildcard میانی.
   - `regex`: الگوی آزاد (فقط ادمین).
3. پاسخ به **اولین تطبیق** (ترتیب: بلندترین کلیدواژه اول — جلوگیری از اینکه «قوانین» با «قانون» اشتباه شود).

### رفتار
- فیلتر فقط روی پیامهای **کاربران عادی** اعمال میشود (پیشفرض)؛ `setfilter scope <all/admins-too>` برای حالت داخلی.
- اگر پیام همزمان blacklist داشت → اولویت با blacklist (حذف) و فیلتر پاسخ نمیدهد (جلوگیری از «پاسخ به اسپم»).
- پاسخ فیلترها **بهمدت ۱۰ ثانیه Rate-limit میشود** (اگر ۵ نفر همزمان «سلام» بگویند، ۱ پاسخ + بقیه فقط دیده نمیشوند؟ خیر — پاسخ تکراری به ۵ نفر در ۵ ثانیه → تلگرام محدود میکند؛ صف پاسخها با فاصلهٔ ۱ ثانیه ارسال شود).

## ۶.۲. نوتهای اداری (Notes / Saved Replies)

| دستور | سطح | رفتار |
|---|---|---|
| `save <name>` (ریپلای) | 🟡 | ذخیره با نام کوتاه (لاتین یا فارسی) |
| `#name` در هر پیام | 🟡 (فقط ادمین) | ارسال محتوای نوت (در هر کجای متن: «ببینید #rules») |
| `/get <name>` | 🟡 | ارسال نوت |
| `notes` | 🟡 | فهرست نوتها |
| `stopnote <name>` | 🟡 | حذف نوت |
| `clear notes` | 🔵 | پاکسازی همه |

- نوت = متن/مدیا/دکمه (همانند فیلتر). موارد پیشنهادی: `#rules` قوانین، `#welcome_guide` راهنمای تازهواردها، `#source` لینک منبع، `#faq1`.
- نوتها **هرگز برای کاربر عادی** با `#` فراخوانی نمیشوند (اگر کاربر عادی `#rules` بفرستد، نادیده گرفته میشود مگر `setnotes public on`).

## ۶.۳. پاسخهای خودکار اجتماعی (Auto-Reply)

| دستور | پیشفرض | رفتار |
|---|---|---|
| `setgreeting on/off` | خاموش | پاسخ به «سلام/درود/hello/hi/…» با پیام خوشآمد کوتاه |
| «پاسخ خودکار» | — | معادل فارسی |
| `setgreeting text <...>` | — | متن دلخواه؛ پیشفرض: «سلام {name} 👋 چطور میتوانم کمکت کنم؟» |
| `greetings` | 🔵 | فهرست فعال |

- **ضد اسپم پاسخ:** هر کاربر حداکثر ۱ پاسخ خوشآمد در ۱۰ دقیقه؛ فقط به اولین پیامِ کاربر در آن بازه.
- چرخش ۳ پاسخ تصادفی برای جلوگیری از حالت رباتیک (`setgreeting cycle on`).

## ۶.۴. حالت FAQ (اختیاری/پیشرفته)

- `faq on/off` + `addfaq <q> | <a>` — پایگاه پرسش/پاسخ گروه.
- اگر پیام کاربر با پرسشی (شباهت ≥ ۷۰٪ با معیار فاصلهٔ لوناشتاین/ترتیب کلمات) تطبیق یافت → پاسخ خودکار + دکمهٔ «❓ این پاسخ کمکت کرد؟ [👍/👎]».
- آمار 👎 پایین → پیشنهاد به ادمین: «پرسش «X» ۵ بار 👎 خورده — پاسخ را بهروز کنید.»
- اگر پاسخی یافت نشد و پرسش علامت «؟» داشت → «من پاسخ دقیق را نمیدانم؛ از ادمینها بپرسید: {adminlink}».

## ۶.۵. دکمههای شیشهای (Inline Buttons در پاسخها)

متن/مدیا/نوتها میتوانند دکمههای URL یا Callback داشته باشند:
```
ساخت: «filter ورودیها» ← ریپلای به پیامی که دارد:
[📚 راهنمای کامل](url)  [👥 ثبتنام](url)
```
- حداکثر ۸ دکمه/۲ ردیف در پاسخ فیلترها؛ بیش از آن خطای «تعداد دکمهها زیاد است» (با برش و اعلان به مدیر).

---

## ۶.۶. داده (Schema)
```jsonc
filters: { chat_id, keyword, type:"text|photo|video|...", content: "<text|file_id>", buttons: [...], mode:"word|glob|regex", action:"reply|delete_reply", by, at }
notes:   { chat_id, name, content, by, at }
greetings: { chat_id, enabled, texts:[...], cycle: bool }
```
ایندکس `(chat_id, keyword)`؛ پاکسازی فیلترهای کاربرِ حذفشده در تسک شبانه.
